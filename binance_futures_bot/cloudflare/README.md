# Cloudflare 版本（未完成、無法使用）

> ⚠️ **這個資料夾的程式目前不能部署使用。**

## 原因

實際測試（2026-11-08）發現：**幣安會拒絕所有來自 Cloudflare Workers 的連線**（HTTP 403）。
不管 Worker 在哪個機房執行（芝加哥、達拉斯、首爾、巴黎…），對外連線位址都被判定為美國，
而幣安封鎖美國；正式網和測試網都一樣。指定在東京執行也沒有效果。

因此自動交易程式請用上一層的 Python 版本，放在**亞洲（非美國）的雲端主機**或自己的電腦上執行。

## 這裡有什麼

把 Python 版改寫成 JavaScript 時寫到一半的檔案，保留下來供日後參考
（例如之後若要在 Cloudflare 做「狀態查看網頁」可以沿用）：

- `src/indicators.js`：EMA、RSI、ATR、MACD 指標
- `src/strategy.js`：MACD + RSI 與 EMA 交叉策略
- `src/risk.js`：倉位計算、數量/價格取整、單日虧損上限
- `src/binance.js`：幣安合約介面（簽名、下單、止損止盈）
- `src/text.js`：中文文字
